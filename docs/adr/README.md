# Architecture Decision Records

Le decisioni che modificano contratti, ownership o invarianti usano file immutabili nel formato:

```text
NNNN-titolo-breve.md
```

Ogni ADR contiene almeno stato, contesto, decisione, conseguenze e alternative scartate. Una ADR
accettata non viene riscritta: una decisione successiva la sostituisce dichiarandolo.

Template:

```markdown
# ADR-NNNN — Titolo

> Stato: proposta | accettata | sostituita
> Data: YYYY-MM-DD

## Contesto

## Decisione

## Conseguenze

## Alternative considerate
```
